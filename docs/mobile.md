# Mobile companion

The desktop wallet is the product. A mobile companion is planned later and is not required for Windows releases.

## Intended scope

- Watch balances and receive addresses for portfolios that already exist on desktop
- Optionally approve or reject spends started on desktop
- No hot seed on the phone in the first companion design — pair with an encrypted one-time secret
- Same warm-dark visual language as the desktop app

## Status

Not started as an application. Desktop APIs (`portfolio_balances`, `portfolio_receive_uri`, vault export) are the foundation for a later pairing flow.
