# Opal releases (binaries only)

Public installer + auto-update artifacts for [Opal](https://github.com/lilathy/opal).

Source code lives in the private `opal` repository. This repo only hosts signed
Windows installers and `latest.json` used by the in-app updater.

## Install

Download the latest `.exe` from [Releases](https://github.com/lilathy/opal-releases/releases/latest).
